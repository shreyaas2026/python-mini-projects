# Python Mini Projects

A collection of small Python projects created to practice programming fundamentals, problem-solving, file handling, data processing, and simple automation.

## Projects

### 1. Number Guessing Game
A command-line game where the user tries to guess a randomly generated number.

**Skills used:**
- Variables and data types
- `if` / `else` conditions
- `while` loops
- User input
- Error handling
- Random number generation

### 2. CSV Data Cleaner
A Python script that reads a CSV file, removes duplicate records, cleans extra spaces from text fields, and creates a cleaned output CSV file.

**Skills used:**
- CSV file handling
- Lists and dictionaries
- String methods
- Duplicate removal
- Reading and writing files

### 3. File Renamer
A Python script that safely renames files in a selected folder using a consistent numbering format.

**Skills used:**
- File and folder handling
- `os` module
- Loops
- String formatting
- Basic automation

## Requirements

- Python 3.x

## How to Run

1. Download or clone this repository.
2. Open a terminal in the relevant project folder.
3. Run the required Python file:

```bash
python filename.py
```

Replace `filename.py` with the actual filename, for example:

```bash
python number_guessing_game.py
```

These are personal learning projects built to strengthen practical Python programming skills. Each project is created and tested independently.
